# Unity 2022.3–6000.2 Module Guide

Use the package's Legacy Host through `ILegacyToolbarModule`. Do not perform toolbar reflection in the module; the package Host owns it.

## Example: Open Project Folder

Create the following Editor-only module in the project rather than the package:

```csharp
using System.IO;
using NKStudio.CustomToolbar;
using UnityEditor;
using UnityEditor.UIElements;
using UnityEngine;

[InitializeOnLoad]
internal sealed class OpenProjectFolderToolbarModule
    : IToolbarModule, ILegacyToolbarModule
{
    private const string ModuleId = "Game.Toolbar.OpenProjectFolder";

    private ToolbarButton _button;

    static OpenProjectFolderToolbarModule()
    {
        ToolbarModuleRegistry.Register(new OpenProjectFolderToolbarModule());
    }

    public string Id => ModuleId;

    public void Refresh(ToolbarRefreshReason reason)
    {
        if (_button != null)
            _button.SetEnabled(ToolbarAvailability.InEditMode);
    }

    public void BuildLegacy(LegacyToolbarBuilder builder)
    {
        var button = new ToolbarButton(OpenProjectFolder)
        {
            text = "Project Folder",
            tooltip = "Open the current project folder."
        };

        button.SetEnabled(ToolbarAvailability.InEditMode);
        builder.Add(LegacyToolbarZone.Right, button);
        _button = button;
    }

    private static void OpenProjectFolder()
    {
        string projectPath = Path.GetDirectoryName(Application.dataPath);
        EditorUtility.RevealInFinder(projectPath);
    }
}
```

## Rules

- Add UI only through `LegacyToolbarBuilder.Add(zone, element)`.
- Choose `Left`, `CenterLeft`, `CenterRight`, or `Right` according to the requested placement.
- Store created UI references only to update their text, value, visibility, or enabled state from `Refresh`.
- Recreate callbacks in `BuildLegacy`; the Host clears and rebuilds its containers when necessary.
- Do not subscribe to Editor lifecycle events or schedule periodic UI polling.
